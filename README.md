# Semi-Autonomous Drone for Harbour Logistics

## Overview

A semi-autonomous quadcopter developed for harbour logistics and surveillance applications. The system integrates flight control, GPS navigation, telemetry, sensing, propulsion, and payload capabilities into a single aerial platform.

The project was developed as a practical mechatronics system, involving mechanical assembly, electronics integration, flight-controller configuration, embedded hardware, autonomous mission planning, troubleshooting, and flight testing.

## Objectives

- Develop a stable quadcopter platform for harbour applications
- Implement GPS-based navigation
- Enable semi-autonomous flight and mission planning
- Integrate telemetry for ground-station communication
- Integrate range sensing
- Develop a mechanism for payload transportation
- Test the system under practical flight conditions

## System Architecture

The system consists of:

- Pixhawk flight controller
- GPS module
- 4-in-1 ESC
- Four brushless motors
- LiPo battery
- RC transmitter and receiver
- Telemetry system
- Range sensor
- Payload mechanism

## Hardware

| Component | Model | Purpose |
