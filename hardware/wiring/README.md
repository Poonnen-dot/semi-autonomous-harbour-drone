# Wiring Overview

The electrical system consists of:

- Pixhawk 2.4.8 Flight Controller
- Velox 50A 4-in-1 ESC
- 4 × 2212 920KV Brushless Motors
- 4S 6200mAh LiPo Battery
- NEO-M9N GPS
- FlySky FS-IA10B Receiver
- T10 Telemetry Module
- TFMini Plus Range Sensor

The battery powers the propulsion system through the ESC while the Pixhawk receives regulated power from the power module.

The Pixhawk communicates with:

- GPS
- RC Receiver
- Telemetry
- ESC
- Range Sensor

Future versions of this repository will include detailed wiring diagrams and pin assignments.
